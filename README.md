# 汉诺塔小程序

这是一个用 Python 编写的汉诺塔求解与可视化演示程序，支持自定义盘子数量。

## 功能特点

- 图形化展示三根柱子和不同大小的圆盘
- 点击起始柱和目标柱，手动完成合法移动
- 撤销上一步操作
- 单步查看递归生成的最优解，或调节速度自动播放
- 显示已移动步数、最少步数和进度
- 保留命令行求解方式，并对大量圆盘进行继续确认

## 使用方法

### 图形界面

```bash
python hanoi.py
```

### 命令行模式

```bash
python hanoi.py --cli
```

图形界面需要 Python 自带的 Tkinter。若使用的 Python 发行版未包含 Tkinter，可使用命令行模式。

### 图形界面操作

1. 选择 1 到 10 个圆盘，点击“新游戏”开始。
2. 手动操作时，依次点击圆盘所在柱和目标柱；大圆盘不能放在小圆盘上。
3. 点击“下一步”查看最优解的下一步；点击“自动演示”播放完整解法，并可调节速度。
4. 点击“撤销一步”撤销最近一次移动。

## 关于汉诺塔问题

汉诺塔（Tower of Hanoi）是一个经典的递归问题。问题描述如下：

- 有三根柱子：A、B、C
- 起始时，A 柱上有 n 个盘子，从上到下按大小递增排列
- 目标是将所有盘子从 A 柱移动到 C 柱
- 移动规则：
  1. 每次只能移动一个盘子
  2. 大盘子不能放在小盘子上面
  3. 可以使用 B 柱作为辅助

最少移动步数为 **2^n - 1** 步。
