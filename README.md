# 汉诺塔小程序

这是一个用 Python 编写的汉诺塔问题求解程序，支持自定义盘子数量。

## 功能特点

- 支持自定义盘子数量
- 递归算法求解
- 显示每一步的移动过程
- 输入验证和错误处理
- 大数量盘子的警告提示

## 使用方法

### 运行程序

```bash
python3 hanoi.py
```

或者（如果已添加执行权限）：

```bash
chmod +x hanoi.py
./hanoi.py
```

### 操作说明

1. 运行程序后，输入盘子数量（正整数）
2. 程序会显示每一步的移动过程
3. 输入 `q` 退出程序

### 示例

```

==================================================

```

## 关于汉诺塔问题

汉诺塔（Tower of Hanoi）是一个经典的递归问题。问题描述如下：

- 有三根柱子：A、B、C
- 起始时，A 柱上有 n 个盘子，从上到下按大小递增排列
- 目标是将所有盘子从 A 柱移动到 C 柱
- 移动规则：
  1. 每次只能移动一个盘子
  2. 大盘子不能放在小盘子上面
  3. 可以使用 B 柱作为辅助

最少移动步数为 **2^n - 1** 步。
